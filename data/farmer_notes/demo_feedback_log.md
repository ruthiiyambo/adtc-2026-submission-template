# Demo Feedback Log

Feedback gathered from people testing the shared FarmHand NA demo.

Follow the capture habits in [README.md](README.md): note date, region, species;
record consent; strip names, phone numbers, and other identifying details unless
essential. This log shapes prompts, MCQs, and UI wording — it is not stand-alone
veterinary truth.

## How this feedback was collected

- Channel: public demo link (Cloudflare quick tunnel to the local llama.cpp build)
- Model under test: `Phi-4-mini-instruct-Q4_K_M`
- Note: the shared link is temporary and changes each time the tunnel restarts.

## Entry template

Copy this block for each piece of feedback.

```
### YYYY-MM-DD — <short title>

- Tester context: <role, e.g. farmer / extension officer / vet / other>
- Region: <region or "n/a">
- Species: <cattle / goats / sheep / calves / other>
- Consent to save notes: <yes / no>
- Question asked (paraphrased, PII removed):
  <what the tester typed>
- Model response quality: <good / mixed / poor>
- What worked:
  <clear steps, correct red flags, good plain language, etc.>
- What was wrong or confusing:
  <inaccuracy, unsafe advice, jargon, wrong headings, etc.>
- Language / UI feedback:
  <Oshindonga wording, layout, readability on phone, etc.>
- Action to take:
  <fix prompt / add MCQ / adjust UI text / vet the underlying fact / none>
```
