# Sources

This folder is for the raw references behind FarmHand NA.

The shared source IDs live in
[REGISTRY.md](REGISTRY.md), and the
current teach/test triage lives in
[SORTING_MAP.md](SORTING_MAP.md).
The copy-paste worksheet for turning sources into dataset material lives in
[TEMPLATE.md](TEMPLATE.md).

## Put here

- veterinary leaflets
- extension handouts
- government or NGO livestock guidance
- citation notes or extracted summaries tied to a stable source ID

## Suggested naming

- `NAM_VET_001_short-title.pdf`
- `NAM_VET_001.md`

Use one stable source ID across:

- the saved source file here
- `data/finetune/`
- `eval/mcq/`
- `REPORT.md`

That shared ID is what makes later review and source-filling fast instead of painful.
